# น้องจอมทอง — แชทตอบคำถามวิทยาลัย

ปรับหน้าจอเป็นแชทแนว iMessage เลือกธีมอัตโนมัติ/สว่าง/มืดและสีหลัก มีคำถามลัดระหว่างสนทนา ดาวน์โหลดบทสนทนาเป็นไฟล์ข้อความ และเลือกตัวอย่างหน้าจอ iPhone หรือเต็มจอบนคอมพิวเตอร์ได้จากแถบด้านข้าง ใช้งานได้ทั้งมือถือและคอมพิวเตอร์ บอทยังคุยเล่นและตอบความรู้ทั่วไปได้ด้วย โดยเลือกน้ำเสียงขี้เล่นเมื่อผู้ใช้ชวนคุยหรือขอมุก

ไฟล์ `ui_block.py` และ `program_guide.py` ต้องอยู่โฟลเดอร์เดียวกับ `app.py` ห้ามย้ายหรือลบทิ้ง

## ข้อมูลและคุณภาพคำตอบ
คำถามเกี่ยวกับวิทยาลัยค้นข้อมูลจากหน้าเว็บวิทยาลัยและ Supabase ก่อนตอบ โดยจะตอบเฉพาะเมื่อมีข้อมูลอ้างอิงที่เกี่ยวข้อง และแสดงลิงก์อ้างอิงเมื่อใช้ข้อมูลหน้าเว็บ คำแนะนำเลือกสาขาใช้คู่มือหลักสูตรจากเว็บไซต์วิทยาลัย ส่วนคำถามทั่วไปและการคุยเล่นใช้ความรู้ของโมเดล จึงอาจไม่ใช่ข้อมูลล่าสุด เรื่องสุขภาพ กฎหมาย หรือการเงินควรตรวจสอบกับผู้เชี่ยวชาญอีกครั้ง ไม่ได้ฝึกน้ำหนักโมเดลใหม่ ส่วน FAQ สาธารณะใช้เฉพาะคำถามบริการที่ผ่านการคัดกรอง

ไฟล์ `program_guide.py` เก็บคำอธิบายและคำค้นของสาขาวิชาจากหน้าเว็บทางการ ใช้เพื่อช่วยจับคู่ความสนใจ ไม่รับประกันอาชีพหรือรายได้ ควรทบทวนลิงก์และรายละเอียดเมื่อวิทยาลัยประกาศหลักสูตร/สาขาใหม่

## เริ่มใช้งานบนคอมพิวเตอร์
1. ติดตั้ง Python แล้วเปิด Terminal/Command Prompt ในโฟลเดอร์นี้
2. ติดตั้งไลบรารี: `pip install -r requirements.txt`
3. คัดลอก `.env.example` เป็น `.env` แล้วกรอก `GEMINI_API_KEY`, `SUPABASE_URL` และ `SUPABASE_KEY`
4. เปิดเว็บแอป: `streamlit run app.py`
5. เปิด URL ที่แสดงใน Terminal บนคอมพิวเตอร์ หรือใช้ Network URL จากมือถือที่อยู่ Wi-Fi เดียวกัน

## เตรียมทำแอป Android
แอป Android ที่สร้างด้วย MIT App Inventor จะเปิดหน้าแชตผ่าน WebViewer ดังนั้นต้องเผยแพร่เว็บแชตเป็น URL แบบ HTTPS ที่เข้าถึงได้จากมือถือก่อน URL `localhost` ใช้ได้เฉพาะเครื่องที่เปิดเซิร์ฟเวอร์ และไม่สามารถใส่ลง APK เพื่อให้ผู้อื่นเปิดจากอินเทอร์เน็ตได้ เมื่อมี URL เว็บจริงแล้วจึงตั้งค่าโปรเจกต์ App Inventor และสร้างไฟล์ `.apk` สำหรับดาวน์โหลดได้

## เผยแพร่เว็บให้เปิดจากมือถือได้
1. อัปโหลดไฟล์โปรเจกต์ไปยัง GitHub repository (ตั้งเป็น private ได้)
2. สร้างแอปที่ Streamlit Community Cloud โดยเลือก repository, branch และ `app.py`
3. ใส่ `GEMINI_API_KEY`, `SUPABASE_URL` และ `SUPABASE_KEY` ในช่อง Secrets ของหน้า Advanced settings ห้ามใส่คีย์เหล่านี้ใน repository
4. เมื่อ Streamlit ให้ URL `https://....streamlit.app` แล้ว ให้เปิดทดสอบบนมือถือก่อนนำ URL ไปตั้งเป็นหน้าเริ่มต้นของ WebViewer ใน MIT App Inventor

การ deploy ครั้งนี้จะต้องมีสิทธิ์เข้าถึง GitHub และบัญชี Streamlit Community Cloud ของเจ้าของโปรเจกต์ โดยไฟล์นี้รองรับการอ่าน Secrets ของ Streamlit Cloud และยังอ่าน `.env` สำหรับการรันในเครื่องได้

## ไฟล์ความลับ
อย่าส่ง `.env` หรือคีย์ Supabase/Gemini ให้ผู้อื่น และอย่าอัปโหลดขึ้น GitHub หรือ Streamlit Cloud ในไฟล์โค้ด หากคีย์เคยถูกเผยแพร่ ให้เปลี่ยนคีย์ใหม่ในผู้ให้บริการก่อนใช้งานจริง

`upload.py` ต้องใช้ `SUPABASE_SERVICE_KEY` ซึ่งมีสิทธิ์สูง ใช้เฉพาะในเครื่องของผู้พัฒนาเท่านั้น
